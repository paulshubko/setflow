# SetFlow

Трекер тренувань для залу: три дні (A/B/C), кнопки ваги з кроком 2,5 кг, таймери, відео й фото техніки, прогрес.

Статичний PWA. Дані зберігаються на пристрої (IndexedDB), є резервна копія у файл. За бажанням дані синхронізуються з домашнім сервером (папка `server/`). Кожен користувач має свій акаунт (логін і пароль), дані й програма в різних акаунтах не змішуються.

## Оновлення
При кожному релізі змінюй `VERSION` у `sw.js`, щоб телефони підтягнули нові файли.

## Сервер синхронізації (Mac mini / будь-який Ubuntu)
На сервері, по SSH:

```
curl -fsSL https://raw.githubusercontent.com/paulshubko/setflow/main/server/install.sh | sudo bash
```

Скрипт ставить Node.js, службу `setflow-sync` (автозапуск), створює токен, вмикає публічну https-адресу через Tailscale Funnel і друкує посилання, яке один раз відкривається на телефоні й заповнює налаштування в SetFlow.

- Дані: `/var/lib/setflow/state.json`, щоденні копії: `/var/lib/setflow/backups/` (зберігаються 90 днів).
- Новий токен: `... | sudo bash -s -- --rotate-token`, потім відкрий нове посилання на кожному пристрої.
- Логи: `journalctl -u setflow-sync -n 50`.
- Злиття: історія тренувань лише додається (нічого не губиться), ваги й незавершене тренування беруться з новішої копії.

## Акаунти
- Створити власника: `sudo setflow-user admin` (питає пароль; так само змінюється пароль). Старий єдиний `state.json` при першому запуску копіюється в акаунт `admin`, оригінал лишається.
- Інші люди реєструються самі на екрані «Вхід» у додатку. Ліміти: до 50 користувачів, 10 реєстрацій на годину, 8 невдалих входів на логін за 15 хвилин. Вимкнути реєстрацію: `ALLOW_REGISTER=0` у `/etc/setflow/env`.
- Паролі зберігаються лише як хеш scrypt, сесії як хеш випадкового токена (180 днів). У додатку пароль не зберігається, тільки сесія.
- Старий токен із установки досі працює як вхід в `admin` (запасний вхід, якщо забув пароль). Зміни його через `--rotate-token`, якщо не потрібен.
- Програма (дні, вправи) належить акаунту (`state.program`). Без неї береться вбудований шаблон A/B/C.

## Картинки вправ (сарай)
Для вправ є дві фото (старт і фініш), які плавно змінюють одне одного. Самих картинок у цьому репозиторії немає: вони лежать на домашньому сервері («сарай», шлях `/shed/img/`). Додаток бере адресу з налаштувань синхронізації, тому без підключеного сервера картинок просто не видно (відео й пошук фото лишаються). Після першого завантаження фото кешуються на телефоні й працюють офлайн.

На сервері, по SSH:

```
curl -fsSL https://raw.githubusercontent.com/paulshubko/setflow/main/shed/setup-shed.sh | sudo bash
```

Скрипт завантажує повний каталог (873 вправи з датасету free-exercise-db, ревізія зафіксована, тож id не змінюються), ставить службу `setflow-shed` на `127.0.0.1:8090` і в кінці друкує команду Tailscale Funnel, яка відкриває лише шлях `/shed` (маршрут синхронізації не чіпає).

- Каталог з описами вправ: `<адреса сервера>/shed/catalog.json`.
- Зіставлення вправ SetFlow з id каталогу: константа `PIC` в `index.html`. Щоб додати чи замінити вправу, файли завантажувати не треба: достатньо вказати id з каталогу.
- Вправи без точного відповідника (позначені в `PIC_APPROX`) показують підпис «орієнтир по руху».
- Анімації: для шести вправ замість двох фото показується зациклений ролик з безкоштовного набору RepDB (константа `ANIM` в `index.html`, файли в `shed/anim/`, шлях `/shed/anim/`). Ліцензія CC BY-NC 4.0: лише особисте некомерційне використання, обов'язкова згадка автора. Exercise data & images: RepDB (https://repdb.co). Якщо ролика на сервері немає, показуються фото. Щоб повернути фото для вправи, видали її рядок з `ANIM`.
- Ліцензія зображень не визначена: автор датасету не знає їхнього походження. Тому фото не зберігаються в цьому публічному репозиторії, а лежать лише на твоєму сервері.
