# SetFlow

Трекер тренувань для залу: три дні (A/B/C), кнопки ваги з кроком 2,5 кг, таймери, відео й фото техніки, прогрес.

Статичний PWA. Дані зберігаються на пристрої (IndexedDB), є резервна копія у файл. За бажанням дані синхронізуються з домашнім сервером (папка `server/`).

## Оновлення
При кожному релізі змінюй `VERSION` у `sw.js`, щоб телефони підтягнули нові файли.

## Сервер синхронізації (Mac mini / будь-який Ubuntu)
На сервері, по SSH:

```
curl -fsSL https://raw.githubusercontent.com/paulshubko/setflow/main/server/install.sh | sudo bash
```

Скрипт ставить Node.js, службу `setflow-sync` (автозапуск), створює токен, вмикає публічну https-адресу через Tailscale Funnel і друкує посилання, яке один раз відкривається на телефоні й заповнює налаштування в SetFlow.

- Дані: `/var/lib/setflow/state.json`, щоденні копії: `/var/lib/setflow/backups/` (зберігаються 90 днів).
- Новий токен: `... | sudo bash -s -- --rotate-token`, потім відкрий нове посилання на кожному пристрої.
- Логи: `journalctl -u setflow-sync -n 50`.
- Злиття: історія тренувань лише додається (нічого не губиться), ваги й незавершене тренування беруться з новішої копії.
