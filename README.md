# SetFlow

Трекер тренувань для залу: три дні (A/B/C), кнопки ваги з кроком 2,5 кг, таймери, відео й фото техніки, прогрес.

Статичний PWA без сервера. Дані зберігаються на пристрої (IndexedDB), є резервна копія у файл.

## Оновлення
При кожному релізі змінюй `VERSION` у `sw.js`, щоб телефони підтягнули нові файли.
